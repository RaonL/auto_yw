# auto_yw · Windows Codex 팀

채팅에 업무를 맡기면 팀장·조사·작성·검수 역할이 순서대로 처리하고 진행 화면과 검수된 결과를 제공합니다.

1. 이 저장소를 내려받아 Codex 데스크톱에서 저장소 루트를 프로젝트로 엽니다.
2. PowerShell 7과 로그인된 Codex CLI를 준비합니다.
3. 채팅에 원하는 업무와 참고 자료를 전달합니다.

실행기와 역할별 지침은 [codex-team](codex-team/README.md)에 있습니다. 루트 [AGENTS.md](AGENTS.md)는 채팅 접수와 진행 안내를 담당합니다.

팀장 → 조사 → 작성 → 독립 검수 → 최종 취합. 수정 요청은 기본 한 번까지 자동 처리하며, 외부 발송·게시·결제·배포 등은 사람 승인에서 멈춥니다.

실제 업무 보고서와 실행·인증 기록은 포함하지 않습니다. Codex 이용 한도가 적용되며 PC와 실행 호스트가 유지되어야 합니다.
